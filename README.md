# کلینیک فیزیوتراپی پرتو — وبسایت جدید

وبسایت فول‌استک (Next.js 16) برای کلینیک تخصصی فیزیوتراپی پرتو در بهبهان،
زیر نظر دکتر مهری شاکری‌نسب (دکترای تخصصی فیزیوتراپی).

## ویژگی‌ها

- 🎨 طراحی پریمیوم با glassmorphism، گرادیان و انیمیشن‌های Framer Motion
- 🌐 کاملاً فارسی و RTL
- 📅 رزرو نوبت آنلاین واقعی (۳ روش: تلفنی، تصویری، حضوری) با تقویم و انتخاب ساعت
- 📎 آپلود مدارک پزشکی (رادیولوژی، MRI)
- 📝 بلاگ/مقالات با پنل مدیریت کامل
- ⭐ نظرات مراجعین با تأیید ادمین
- 💬 چت آنلاین با پاسخ خودکار
- 💳 پرداخت آنلاین (دمو)
- 🛠 پنل مدیریت کامل (داشبورد، نوبت‌ها، مقالات، نظرات، پیام‌ها، تنظیمات)
- 🔐 احراز هویت JWT
- 🗄 دیتابیس SQLite با Prisma 7

## اجرای پروژه

```bash
npm install
npx prisma migrate dev
npx tsx prisma/seed.ts
npm run dev
```

پنل مدیریت: `/admin/login` — ایمیل: `admin@parto.online` — رمز: `admin123`

## صفحات

- `/` — خانه
- `/services` — خدمات و تجهیزات
- `/about` — درباره دکتر
- `/articles` — مقالات
- `/articles/[slug]` — جزئیات مقاله
- `/booking` — رزرو نوبت
- `/contact` — ارتباط با ما
- `/admin/*` — پنل مدیریت
