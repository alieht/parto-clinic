# جایگزین Netlify — راهنمای تصمیم و استقرار

## چرا Netlify محدود شد؟

Netlify از سپتامبر ۲۰۲۵ به **پرداخت اعتباری (credit-based)** تغییر کرده:

| مورد | هزینه |
|------|-------|
| پلن رایگان | **۳۰۰ اعتبار در ماه** (سقف سخت) |
| هر گیگابایت پهنای باند | ۲۰ اعتبار → عملاً **~۱۵ GB** |
| هر deploy پروداکشن | ۱۵ اعتبار → عملاً **~۲۰ deploy** |
| وقتی اعتبار تمام شود | سایت **متوقف** می‌شود: «Site not available» |

با ۳۰۰ اعتبار، یک سایت پرترافیک در چند روز سقف را پر می‌کند. این دقیقاً همان چیزی است که دیدید.

به علاوه: کرون هر ۱ دقیقه = ۴۳٬۲۰۰ فراخوانی در ماه. روی Netlify گران/محدود است.

---

## گزینه‌های جایگزین

| پلتفرم | هزینه | Cron داخلی | Node 20 + Prisma | پرداخت از ایران | رتبه |
|--------|-------|------------|------------------|------------------|------|
| **لیارا** (ایرانی) | از ۷۵۰٬۰۰۰ تومان/ماه، پلن رایگان هم دارد | ✅ بومی | ✅ (Docker) | ✅ کارت ایرانی | 🥇 |
| **پارس‌پک** (ایرانی) | مشابه | ✅ | ✅ با Docker | ✅ | 🥈 |
| Vercel Hobby | رایگان | فقط کرون روزانه | ✅ | ❌ احتمال بلاک تحریم + Hobby مخصوص استفاده غیرتجاری | ⚠️ |
| Prisma Compute | رایگان (۱M درخواست/ماه) | ❌ | ✅ | ❌ نیاز به بررسی | ⚠️ |
| Render | رایگان ۷۵۰ ساعت | ✅ | ✅ | ❌ قبلاً برای شما بسته بود | ❌ |
| Cloudflare | رایگان | ✅ | ❌ `pg` روی Workers کار نمی‌کند | — | ❌ |

### چرا لیارا؟

1. **ایرانی است** — کارت بانکی ایرانی، بدون مسئله تحریم، بدون قطع دسترسی
2. **Node نسخه‌اش را می‌شود کنترل کرد** — و مهم‌تر: از مسیر **Docker** استفاده می‌کنیم، پس نسخه Node کاملاً در دست ماست (`node:20-alpine` در `Dockerfile` موجود است). این همان مشکلی است که در پارس‌پک با Node 24 خوردیم و دیگر پیش نمی‌آید.
3. **Cron بومی** — فایل `liara.json` ساخته شد، بدون نیاز به GitHub Actions
4. **پلن رایگان** برای شروع + تعرفه ساعتی
5. **پایین‌ترین تأخیر برای کاربران ایرانی**

## استقرار روی لیارا (قدم به قدم)

### ۱. نصب CLI
```bash
npm install -g @liara/cli
liara login
```

### ۲. ساخت برنامه
- وارد کنسول لیارا شوید → **Create PaaS** → پلتفرم **Next.js**
- شناسه: `parto-clinic`
- پلن: **زمین** (۰.۵۱۲GB RAM) برای شروع کافی است
- Node.js: **20**

### ۳. متغیرهای محیطی
همه‌ی متغیرهای Netlify را عیناً وارد کنید:

```
DATABASE_URL          (همان pooler Supabase، پورت 6543)
JWT_SECRET
ADMIN_EMAIL
ADMIN_PASSWORD
SECRETARY_EMAIL
SECRETARY_PASSWORD
ADMIN_PHONE
SECRETARY_PHONE
SMSIR_API_KEY
CRON_SECRET
DOCTOR_PHONE
VIDEO_LINK_SECRET
```

> چون Supabase از ایران هم در دسترس است، دیتابیس را نگه می‌داریم و مهاجرت داده لازم نیست.

### ۴. استقرار
```bash
cd parto-clinic
liara deploy --platform nextjs
```
یا از کنسول: **استقرار جدید** → آپلود ZIP یا اتصال GitHub.

`liara.json` از قبل ساخته شده و کرون هر دقیقه را تنظیم می‌کند.

### ۵. دامنه
در بخش **دامنه**، `parto.online` را اضافه کنید و رکورد DNS را روی لیارا بگذارید. SSL خودکار است.

> ⚠️ قبل از تغییر DNS، مطمئن شوید سایت روی ساب‌دامین لیارا کامل کار می‌کند.

### ۶. حذف کرون Netlify
بعد از مهاجرت، بخش `[functions."check-video-calls"]` را از `netlify.toml` بردارید (یا Netlify را کلاً خاموش کنید).

## گزینه جایگزین اگر لیارا جواب نداد: GitHub Actions

repo از قبل قالبش را دارد: `docs/github-workflow-video-calls.yml.example`

کافیست آن را به `.github/workflows/video-calls.yml` کپی کنید و دو Secret بسازید:
- `PARTO_BASE_URL` = `https://parto.online`
- `CRON_SECRET` = همان رشته

این کاملاً رایگان است و کرون را از هر پلتفرمی جدا می‌کند. برای Netlify هم کار می‌کند و فقط هزینه فراخوانی را حذف می‌کند (ولی سقف اعتبار پهنای باند را حل نمی‌کند).

## نکته درباره Dockerfile

`Dockerfile` موجود با `node:20-alpine` کار می‌کند و برای هر پلتفرمی که Docker قبول کند (لیارا، پارس‌پک، هر VPS) بدون تغییر قابل استفاده است. اگر جایی نسخه Node را نمی‌توانستید عوض کنید، مسیر Docker این محدودیت را دور می‌زند:

```bash
liara deploy --platform docker
```
